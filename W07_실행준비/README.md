# 본인이 직접 진행할 W07 실습

lab.py와network.json은 제공ZIP에서 그대로 복사했다. 현재 사용자 실행은 미실행이며 아래 예상값은 본인 결과가 아니다. 클라우드 계정·유료 자원·외부 패키지 없이 로컬에서 진행한다.

2026-10-13에 요청에 따라 Copilot이 이 폴더에서 네 모드를 실행했고 출력은 `W07_실행결과_20261013.md`에 기록했다. 이는 실제 로컬 실행 출력이지만 사용자가 직접 실행한 결과는 아니다. 시험·보고서에서 본인 직접 수행 여부를 묻는 경우 두 사실을 구분한다.

1. 이 폴더를 개인 작업 사본으로 복사한다. 교수 예제인지 본인 설계 입력인지 이름으로 구분한다.
2. 터미널에서 사본 폴더를 열고 Python버전, 실제 날짜와 입력을 기록한다.
3. 아래 명령을 하나씩 실행한다. 각 결과를 저장하고 입력·명령·출력·본인 설명이 보이는 화면을 남긴다.

```powershell
python --version
Get-Content .\network.json
python -X utf8 .\lab.py cidr
python -X utf8 .\lab.py overlap
python -X utf8 .\lab.py routes
python -X utf8 .\lab.py mapping
```

cidr는network.json을 읽고 포함·중복을 계산한다. 예제의/24는통상251가용주소,4개포함True,중복0이 예상된다. overlap은메모리에서private-a안의뒤쪽/25를private-b로넣어중복1을검사한다. 실제 파일은변하지않는다.

routes/mapping은코드내고정표다. 본인CSV·도면을읽지않는다. routes의NAT와none은서로다른예제조건이다. mapping의G04수정은제공코드의관찰이며본인실제오류수정으로쓰지않는다.

4. 새 사본에서VPC와모든서브넷을본인이선택한주소로바꾸고전후파일을보존한다. 제공자료의10.20예시는참고값이며자동으로본인선택이되는것은아니다.
5. 본인경로표·보안표·도면을규칙번호/출발지/대상/포트/REQ별로대조한다. W05와W07은같은G번호라도뜻이다를수있으므로W07범위를명시한다.
6. 본인의입력·결과·해석을주차별보고서와개인과제증거에연결한다. 실제VPC접속·부하·복구를시험하지않았다면미실행으로표시한다.

상위실습실행.py는이번ZIP에포함되지않아그도우미명령을사용하지않는다. 교수제공로그·이번AI검산·본인직접실행의출처를섞지않는다.
