# W07 로컬 실습 실행 결과

- 실행일: 2026-10-13
- 실행 주체: Copilot 보조 실행 (학생 본인 실행 결과가 아님)
- 실행 위치: `과제1_20261013/W07_실행준비`
- Python: 3.13.7
- 입력 파일: `network.json` (제공된 초기값, 아래 기록에는 수정 없음)
- 프로그램: `lab.py`

> 이 기록은 요청에 따라 보조 도구가 로컬에서 실행한 결과다. 학생 본인의 직접 실행·설명·제출 증거로 표시하지 않는다. 클라우드 자원을 생성하거나 실제 패킷/서비스 연결을 시험하지 않았다.

## 실행 입력

실행 전 `network.json` 내용:

```json
{
  "vpc": "10.0.0.0/16",
  "subnets": {
    "public-a": "10.0.1.0/24",
    "public-b": "10.0.2.0/24",
    "private-a": "10.0.11.0/24",
    "private-b": "10.0.12.0/24"
  }
}
```

실행한 명령:

```powershell
& 'C:\Program Files\Python313\python.exe' --version
Get-Content .\network.json -Raw
& 'C:\Program Files\Python313\python.exe' -X utf8 .\lab.py cidr
& 'C:\Program Files\Python313\python.exe' -X utf8 .\lab.py overlap
& 'C:\Program Files\Python313\python.exe' -X utf8 .\lab.py routes
& 'C:\Program Files\Python313\python.exe' -X utf8 .\lab.py mapping
```

## 실제 출력

### Python 버전

```text
Python 3.13.7
```

### `cidr`

```text
public-a 10.0.1.0/24 inside= True usable= 251
public-b 10.0.2.0/24 inside= True usable= 251
private-a 10.0.11.0/24 inside= True usable= 251
private-b 10.0.12.0/24 inside= True usable= 251
overlap_pairs= 0 []
exit_code=0
```

관찰: 네 CIDR이 VPC `10.0.0.0/16` 안에 있다고 계산됐고, 서로 겹치는 쌍은 0개였다. 코드의 `usable=251`은 IPv4 `/24`에서 주소 256개 중 5개를 빼는 예제 계산이다. 이 값만으로 실제 배치 가능 인스턴스 수나 연결 가능 여부를 증명하지 않는다.

### `overlap`

```text
public-a 10.0.1.0/24 inside= True usable= 251
public-b 10.0.2.0/24 inside= True usable= 251
private-a 10.0.11.0/24 inside= True usable= 251
private-b 10.0.11.128/25 inside= True usable= 123
overlap_pairs= 1 [('private-a', 'private-b')]
exit_code=0
```

관찰: `private-a`의 뒤쪽 절반인 `10.0.11.128/25`를 실행 중 메모리에서 `private-b`로 대체해 의도적으로 겹침을 만들었고, 겹치는 쌍 1개가 탐지됐다. `network.json` 파일 자체는 수정하지 않았다. 이 결과는 반례 검사이며 원래 네트워크 파일의 중첩 결과가 아니다.

### `routes`

```text
코드 내부 고정 경로 예제입니다. 본인 경로 CSV는 읽지 않습니다.
public-a 0.0.0.0/0 → igw : public
public-b 0.0.0.0/0 → igw : public
private-a 0.0.0.0/0 → nat : private with egress
private-b 0.0.0.0/0 → none : isolated
NAT 기본경로가 있어도 사설 서브넷이다
exit_code=0
```

관찰: 출력은 `lab.py`에 하드코딩된 경로 예제다. 개인 경로표·CSV·AWS 라우트 테이블을 읽거나 검증하지 않았다. 실제 VPC 경로와 연결성 테스트 결과가 아니다.

### `mapping`

```text
코드 내부 고정 도면·규칙 예제입니다. 본인 CSV·도면은 읽지 않습니다.
before: mismatched= ['G04']
after: mismatched= []
G01 internet → alb:443
G02 alb → web:80
G03 web → app:8080
G04 app → db:5432
internet_to_db= False
관리 경로는 승인된 별도 요구로 추가; 실제 패킷 시험 아님
exit_code=0
```

관찰: 예제 코드가 먼저 G04 포트 불일치를 표시한 뒤 코드 내부 규칙을 `3306`에서 `5432`로 바꿔 불일치를 없앴다. 개인 도면·보안 그룹 규칙표를 읽거나 수정하지 않았다. `internet_to_db=False`도 이 고정 예제의 직접 화살표만 확인한 결과이며 실제 네트워크 보안 검증이 아니다.

## 결과 요약과 한계

| 모드 | 실제 관찰 | 검증 범위 |
|---|---|---|
| `cidr` | 네 서브넷 포함 `True`, 중첩 0쌍 | 제공된 JSON의 CIDR 산술 |
| `overlap` | 의도적 중첩 1쌍 탐지 | 메모리에서 만든 반례 |
| `routes` | 고정 예제 경로 4개 출력 | 프로그램 내부 표의 설명 출력 |
| `mapping` | 고정 G04 불일치가 수정 후 0개 | 프로그램 내부 도면·규칙 데이터 비교 |

모든 명령은 종료 코드 0으로 마쳤다. 이것은 프로그램의 정상 종료를 뜻할 뿐, 개인 설계의 타당성·AWS 배포 성공·부하 충족·RTO 달성·보안 완전성을 의미하지 않는다. 본인 CIDR·AZ·경로·보안 규칙과 최종 도면은 별도로 정하고 대조해야 하며, 직접 수행한 제출 증거가 필요하면 학생 본인이 개인 사본에서 다시 실행하고 본인의 해석과 함께 기록해야 한다.
